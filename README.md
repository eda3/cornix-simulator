# cornix-simulator

分割キーボード「Cornix LP」のキー配列とレイヤーを、手元のふつうのキーボードで試せる、ブラウザ用のシミュレータです。

**非公式の物です。** メーカーとは関係のない、個人の制作物です。

## 何をする物か

- Cornix LP を買う前に、「48キーの配列とレイヤーでやっていけるか」を、自分の手で確かめるための物です。
- 再現するのは、論理の側（キーの数と並び・レイヤー・出る文字）です。打鍵感と姿勢は、対象の外です。
- キーマップは、Vial の保存ファイル（.vil）を、ページで読み込んで使います。

## 使い方（予定）

実装の前に書いた予定です。実物ができたら、書き直します。

1. ページを開く（公開先は `https://eda3.github.io/cornix-simulator/` の予定）。最初は、見本のキーマップが出ていて、すぐ試せます。
2. 手元のキーボードで打つと、図の中の対応するキーが光り、出た文字が欄に並びます。レイヤーを切り替えるキー（MO）を押している間は、図が、そのレイヤーに変わります。
3. Cornix の初期キーマップで試すときは、下の入手先から `cornix-default-keymap.vil` を入手して、「.vil を選ぶ」で読み込みます。
4. Ctrl・Win・Alt も試すときは、「全画面で試す」を押します（ふつうの窓では、Ctrl+W でタブが閉じ、Win キーでスタートメニューが開きます）。
5. 出る文字は、PC の側の配列（JIS か US）で変わります。画面で切り替えられます（初期値は JIS）。
6. キーの割り当てを変える常駐ソフト（keyhac など）は、止めて使います。

## .vil の入手先

Cornix の初期キーマップ（`cornix-default-keymap.vil`）は、公式マニュアルの「初期キーマップ」にあります。

- [Cornix 日本語マニュアル](https://docs.channel.io/jezailfunderjp/ja/articles/Cornix-%E6%97%A5%E6%9C%AC%E8%AA%9E%E3%83%9E%E3%83%8B%E3%83%A5%E3%82%A2%E3%83%AB-c1160246)

このリポジトリには、公式の .vil を置いていません（配り直してよいかが、未確認のため）。Cornix の持ち主が Vial で保存した .vil も、読み込めます。

## 対象

- ブラウザ: Windows の Chrome と Edge。ほかのブラウザは、確かめていません。
- 手元のキーボード: 日本語配列（JIS）向けの対応表を持っています。

## できないこと（最初の版）

次の物は動きません。図には「未対応」と出ます。

- 長押しと短押しで役割が変わるキー（LT・MT など）、MO 以外のレイヤーの切り替え、コンボ、タップダンス、マクロ
- Bluetooth の切り替え、マウスと音量のキー、左右の内側にある丸い部品（押し込みと回転）
- 日本語入力（IME）、練習文と計測

## キーの座標の出どころ

図のキーの位置と角度は、公式ファームウェア V1.12 に埋め込まれている、Vial 用の機種定義から取った値です（[docs/design.md](docs/design.md) の 3.3節）。この値を使うことについて、**メーカーの許可は未確認**です。
