# cornix-simulator

分割キーボード「Cornix LP」のキー配列とレイヤーを、手元のふつうのキーボードで試せる、ブラウザ用のシミュレータです。

**非公式の物です。** メーカーとは関係のない、個人の制作物です。

## 何をする物か

- Cornix LP を買う前に、「48キーの配列とレイヤーでやっていけるか」を、自分の手で確かめるための物です。
- 再現するのは、論理の側（キーの数と並び・レイヤー・出る文字）です。打鍵感と姿勢は、対象の外です。
- キーマップは、Vial の保存ファイル（.vil）を、ページで読み込んで使います。

## 使い方

公開先: https://eda3.github.io/cornix-simulator/

1. ページを開くと、見本のキーマップが出ていて、すぐ打てます。
2. 手元のキーボードで打つと、図の中の対応するキーが光り、出た文字が欄に並びます。修飾キーの札（Shift・Ctrl・Alt・GUI）と、「直前のキー」（押した組み合わせと、出た文字）も出ます。
3. レイヤーを切り替えるキー（MO）を押している間は、図の刻印が、そのレイヤーの物に変わります。下のレイヤーから透けて見えているキーは、刻印を薄く出します。
4. レイヤーの列の番号のボタンを押すと、そのレイヤーの中身を、そのまま眺められます。「自動」で、元に戻ります。
5. Cornix の初期キーマップで試すときは、下の入手先から `cornix-default-keymap.vil` を入手して、「.vil を選ぶ」で読み込みます。動かない物（未対応のキー・コンボ・タップダンス・マクロ）があると、その数が出ます。
6. 出る文字は、PC の側の配列（JIS か US）で変わります。画面で切り替えられます（初期値は JIS）。
7. 図のキーの隅には、当たっている手元のキーの名前が出ます。「手元のキーの名前」のチェックを外すと、消えます。
8. Ctrl・Win・Alt も試すときは、「全画面で試す」を押します（ふつうの窓では、Ctrl+W でタブが閉じ、Win キーでスタートメニューが開きます）。戻るときは、マウスを画面の上へ動かすと出るボタンか、このページの「全画面をやめる」を使います。
9. キーが押されたままに見えるときは、「キーを全部離す」を押します。欄は「全部消す」で空になります。
10. キーの割り当てを変える常駐ソフト（keyhac など）は、止めて使います。
11. 設定と、読み込んだ .vil は、ブラウザに覚えません。開き直すと、見本のキーマップと初期値（JIS・手元のキーの名前を出す・「自動」）に戻ります。

計測ページ（https://eda3.github.io/cornix-simulator/keytest.html ）は、手元のキーがブラウザにどう届くか（code・key・keyup が来るか）を見るページです。キーボードや常駐ソフトを変えたときに、測り直すのに使います。

## .vil の入手先

Cornix の初期キーマップ（`cornix-default-keymap.vil`）は、公式マニュアルの「初期キーマップ」にあります。

- [Cornix 日本語マニュアル](https://docs.channel.io/jezailfunderjp/ja/articles/Cornix-%E6%97%A5%E6%9C%AC%E8%AA%9E%E3%83%9E%E3%83%8B%E3%83%A5%E3%82%A2%E3%83%AB-c1160246)

このリポジトリには、公式の .vil を置いていません（配り直してよいかが、未確認のため）。Cornix の持ち主が Vial で保存した .vil も、読み込めます。

## 手元のキーとの対応

初版の対応表は、109配列の日本語配列（JIS）のキーボード向けです（表は [docs/design.md](docs/design.md) の 3.4節）。画面では変えられません。

- 上の3段（36キー）は、手元のキーボードの同じ位置のキーです。左端の列は、上から Tab・英数（CapsLock）・左 Shift。右端の列は、上から @・:・ろ。英数の位置には、Esc も当たります。
- 下段は、左から右へ、左手が Ctrl・Win・（手元のキー無し）・Alt・無変換・Space、右手が Enter・カタカナひらがな・Alt・Win・アプリケーション・Ctrl です。カタカナひらがなの位置には、Backspace も当たります。
- 変換のキーは使いません（作者の環境では、変換のキーの keydown がページに届かなかったため）。その位置には、代わりに Enter を当てています。
- 対応表に無い手元のキー（数字の段・[・]・右 Shift・F キー・矢印など）は使いません。押すと、ブラウザのふつうの動きになります。

## 対象

- ブラウザ: 対象は、Windows の Chrome と Edge です。ほかのブラウザは、確かめる対象にしていません。
- 対象のブラウザで作者が確かめたのは、Edge の全画面＋Keyboard Lock（Win キーと Ctrl+W がページに届く）です。Chrome では、まだ確かめていません。
- 対象の外の Brave でも、作者の手元では、開いたときの見え方・打つ・.vil を選ぶ・切り替えが動きました。Brave は Keyboard Lock が無いので、全画面にはなりますが、Win キーなどは受けられません（そのことを、注意の文で出します）。
- キーボード: 実測は REALFORCE Mac用 JIS＋KeySwap の環境で行いました。CapsLock・カタカナひらがな・右 Win のキーは、手元のキーボードに無いので、未実測です。

## できること

- .vil の48キーのキーコードを、図に出します。丸い部品2つも、形だけ描きます。
- レイヤーの切り替えは MO（押している間だけ）。KC_TRNS（透明）は、下の有効なレイヤーのキーを使います。
- 文字のキーと、Shift 付きのキーコード（KC_EXLM・LSFT(KC_1) など）は、欄に文字を足します。Enter は改行、Tab はタブ文字、Space は空白を足し、Bksp は1文字消します。押し続けると、繰り返します。
- 修飾キー（左右の Ctrl・Shift・Alt・GUI）は、押している間だけ入ります。
- 文字にならないキー（Esc・F1・矢印など）と、Ctrl・Alt・GUI との組み合わせは、欄を変えず、「直前のキー」に名前が出ます。

## できないこと（最初の版）

次の物は動きません。図には「未対応」と出て、押しても何も出ません。

- 長押しと短押しで役割が変わるキー（LT・MT など）、MO 以外のレイヤーの切り替え（TG・TO・DF・OSL・TT など）、ワンショットの修飾（OSM）
- コンボ、タップダンス、マクロ、キーの上書き（key_override）
- Bluetooth の切り替えなど（USER00 など）、マウスと音量のキー、左右の内側にある丸い部品（押し込みと回転）
- 修飾つきのキーコードのうち、Shift 以外（LCTL(KC_C) など）

ほかに、次のこともできません。

- 日本語入力（IME）。CapsLock の状態も持ちません
- 練習文と、打つ速さの計測
- ページの中で、キーの割り当てを変えることと、.vil の書き出し

## キーの座標の出どころ

図のキーの位置と角度は、公式ファームウェア V1.12 に埋め込まれている、Vial 用の機種定義から取った値です（[docs/design.md](docs/design.md) の 3.3節）。この値を使うことについて、**メーカーの許可は未確認**です。

## 手元で動かす

要る物: Rust と、wasm32-unknown-unknown のターゲット、[wasm-pack](https://github.com/wasm-bindgen/wasm-pack)、Python（静的なファイルを配るのに使います）。作者が確かめた版は、rustc 1.98.0・wasm-pack 0.15.0・Python 3.12.10 です。

```sh
rustup target add wasm32-unknown-unknown
wasm-pack build cornix_web --target web --out-dir ../static/pkg --no-typescript
python -m http.server 8000 --directory static
```

サーバーを動かしたまま、`http://localhost:8000/` を開きます（計測ページは `http://localhost:8000/keytest.html`）。`file://` で開くと、WASM を読み込めません。ビルドの結果（`static/pkg/`）は、git に入れません。

テストは `cargo test --workspace` で回ります（ブラウザは要りません）。
